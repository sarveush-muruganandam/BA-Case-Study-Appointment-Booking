# Online Appointment Booking System: Business Analysis Case Study

A self-initiated Business Analysis case study for **CareFirst Clinic**, a fictional multi-specialty clinic with 12 doctors across 5 departments. The clinic books appointments by phone and walk-in, which causes double-bookings, long queues and missed appointments. This case study defines the requirements for an online booking system that fixes this.

> The client, pain points and targets are fictional and assumed for demonstration. This is a practice project, not a real engagement.
